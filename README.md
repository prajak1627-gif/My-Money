# บันทึกรายรับ-รายจ่าย (Google Apps Script + Google Sheets)

เว็บแอปบันทึกรายรับ-รายจ่ายส่วนตัว ใช้งานผ่านมือถือได้สะดวก แยกประเภท "กระเป๋า" (บัญชี/เงินสด) และ "หมวดหมู่" ได้เอง มี Dashboard สรุปยอด กราฟ Donut สัดส่วนรายจ่าย และระบบตัดรอบบัญชี — ข้อมูลทั้งหมดเก็บใน Google Sheets ของคุณเอง ไม่มีค่าใช้จ่าย

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | โค้ดฝั่งเซิร์ฟเวอร์ (API อ่าน/เขียนข้อมูลลง Google Sheets) |
| `Index.html` | หน้าเว็บทั้งหมด — รวม HTML, CSS (สไตล์) และ JavaScript ไว้ในไฟล์เดียว |

มีแค่ 2 ไฟล์เท่านั้น เพื่อไม่ให้สับสนเรื่องชนิดไฟล์ตอนสร้างใน Apps Script Editor

## ขั้นตอนติดตั้ง (ใช้เวลาประมาณ 5 นาที)

### 1) สร้าง Google Sheet
1. ไปที่ [sheets.google.com](https://sheets.google.com) → สร้างสเปรดชีตใหม่ ตั้งชื่อ เช่น "บันทึกรายรับ-รายจ่าย"
2. ไม่ต้องสร้างชีตย่อยเอง — ระบบจะสร้างให้อัตโนมัติตอนเปิดแอปครั้งแรก (`Wallets`, `Categories`, `Transactions`, `Periods`)

### 2) เปิด Apps Script
1. ในสเปรดชีต ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. จะเปิดหน้าต่าง Apps Script Editor ที่ผูกกับสเปรดชีตนี้อยู่แล้ว

### 3) วางโค้ด (มีแค่ 2 ไฟล์)
1. ลบโค้ดเริ่มต้นในไฟล์ `Code.gs` (ไฟล์ Script ที่มีอยู่แล้ว) ทิ้ง แล้ววางเนื้อหาจากไฟล์ `Code.gs` ที่ให้มาแทน
2. สร้างไฟล์ใหม่ 1 ไฟล์: คลิก **+ ข้าง Files → เลือก HTML** (ไม่ใช่ Script) ตั้งชื่อว่า `Index` แล้วกด Enter — จะได้ไฟล์ `Index.html`
3. ลบเนื้อหาเริ่มต้นในไฟล์ `Index.html` แล้ววางเนื้อหาทั้งหมดจากไฟล์ `Index.html` ที่ให้มาแทน (ไฟล์นี้รวม CSS และ JavaScript ไว้ในตัวแล้ว ไม่ต้องสร้างไฟล์แยกอีก)
4. กด **บันทึก** (ไอคอนรูปแผ่นดิสก์ หรือ Ctrl+S)

### 4) เผยแพร่เป็นเว็บแอป
1. มุมขวาบน คลิก **Deploy (ทำให้ใช้งานได้จริง) → New deployment**
2. คลิกไอคอนรูปเฟือง ข้าง "Select type" → เลือก **Web app**
3. ตั้งค่า:
   - **Execute as**: Me (บัญชีของคุณ)
   - **Who has access**: เลือก "Only myself" ถ้าจะใช้คนเดียว หรือ "Anyone" ถ้าจะแชร์ให้คนอื่นใช้ (แต่ทุกคนจะเห็นข้อมูลชุดเดียวกันในชีตเดียวกัน)
4. คลิก **Deploy** → ระบบจะขอ **Authorize access** ครั้งแรก ให้กด "Advanced" → "Go to (ชื่อโปรเจกต์) (unsafe)" → Allow (เป็นการอนุญาตให้สคริปต์เข้าถึงสเปรดชีตของคุณเอง ไม่มีอะไรน่ากังวล)
5. จะได้ **Web app URL** — นี่คือลิงก์เว็บแอปของคุณ กดเปิดได้เลย หรือ **Add to Home Screen** บนมือถือให้เหมือนแอปจริง

### 5) อัปเดตโค้ดในอนาคต
ถ้าแก้โค้ดแล้วอยากให้เว็บแอป (ลิงก์เดิม) อัปเดตตาม ต้องไปที่ **Deploy → Manage deployments → แก้ไข (ไอคอนดินสอ) → เปลี่ยน Version เป็น "New version" → Deploy** ทุกครั้ง (แก้โค้ดอย่างเดียวไม่พอ ต้องกด deploy version ใหม่ด้วย)

## โครงสร้างข้อมูลใน Google Sheets

ระบบจะสร้าง 4 ชีตให้อัตโนมัติ:

- **Wallets** — กระเป๋า/บัญชี (ชื่อ, ไอคอน, สี, ยอดตั้งต้น)
- **Categories** — หมวดหมู่รายรับ/รายจ่าย (ชื่อ, ประเภท, ไอคอน, สี)
- **Transactions** — รายการรับ-จ่ายทั้งหมด (วันที่, ประเภท, กระเป๋า, หมวดหมู่, จำนวนเงิน, โน้ต, รอบบัญชีที่สังกัด)
- **Periods** — รอบบัญชี (ชื่อ, วันเริ่ม, วันสิ้นสุด, สถานะ active/closed)

คุณสามารถเปิดชีตเหล่านี้ดูหรือแก้ไขข้อมูลตรงๆ ได้ตลอดเวลา แอปจะอ่านค่าล่าสุดเสมอ

## หลักการทำงานที่ควรรู้

- **ยอดคงเหลือของกระเป๋า** = ยอดตั้งต้น + รายรับสะสมทั้งหมด − รายจ่ายสะสมทั้งหมด (นับทุกรอบบัญชี ไม่ใช่แค่รอบที่เลือกดู) เพราะเป็นเงินจริงที่มีอยู่
- **สรุปรายรับ/รายจ่าย และกราฟ Donut บนหน้า Dashboard** จะคำนวณเฉพาะรายการ **ในรอบบัญชีที่เลือกดู** เท่านั้น
- **ตัดรอบบัญชี** (ปุ่ม "✂️ ตัดรอบ" หน้า Dashboard) = ปิดรอบปัจจุบันด้วยวันที่ที่กำหนด แล้วเปิดรอบใหม่ต่อให้อัตโนมัติ เหมาะสำหรับตัดรอบรายเดือน/รายสัปดาห์ตามที่คุณกำหนดเอง
- ลบกระเป๋า/หมวดหมู่/รอบบัญชีไม่ได้ถ้ายังมีรายการผูกอยู่ (ป้องกันข้อมูลเพี้ยน) ต้องลบหรือย้ายรายการออกก่อน

## ปรับแต่งเพิ่มเติมได้ที่ไหน

- สีธีม/ฟอนต์ → แก้ในไฟล์ `Index.html` ส่วนที่อยู่ระหว่างแท็ก `<style>...</style>` (ตัวแปร `:root` ด้านบน)
- ไอคอน/สีตั้งต้นให้เลือกตอนเพิ่มกระเป๋า-หมวดหมู่ → แก้ array `ICON_PRESETS` / `COLOR_PRESETS` ในส่วนแท็ก `<script>...</script>` ของ `Index.html`
- หมวดหมู่/กระเป๋าเริ่มต้นตอนใช้งานครั้งแรก → แก้ฟังก์ชัน `seedDefaultsIfEmpty_()` ใน `Code.gs`
